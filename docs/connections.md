# External connections

None. BenchLink makes no outbound network requests and needs no credentials.

- SportsEngine data arrives only as an uploaded CSV roster export that a league
  admin chooses in the browser; there is no live SportsEngine API connection.
- The app sends no messages: no SMS, no email, no push notifications. When a sub
  is confirmed the captains and the sub contact each other themselves using the
  details BenchLink shows them.
